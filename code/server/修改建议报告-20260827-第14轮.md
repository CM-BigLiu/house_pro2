## 二、🔴 新发现并已修复：WebSocket JWT secret 兜底值不一致

**现象**：版本统一到 10.4.22 后，WebSocket 仍失败——连接成功但 `ping` 无 `pong`、连接被服务端主动断开（`io server disconnect`）。

**根因**（逐层日志定位）：`events.module.ts` 与 `auth.module.ts` 的 `JwtModule` 兜底 secret 不一致：

| 模块 | secret 兜底值 | 与 .env 一致？ |
|---|---|---|
| auth.module（签发 token） | `'house_pro_jwt_secret_key_change_in_production'` | ✅ 一致 |
| events.module（验证 token） | `'default-secret'` | ❌ 不一致 |

因 `JwtModule.register({ secret: process.env.JWT_SECRET || 'xxx' })` 在模块 import 时求值，此时 `ConfigModule` 尚未把 `.env` 读入 `process.env`，于是两模块各自落到兜底值 → secret 不一致 → WebSocket 端 `WsJwtGuard` 验证 JWT 抛异常 → `client.disconnect()`。

**修复**（已改并验证）：把 `events.module.ts` 兜底值改为与 auth.module 一致：

```ts
// code/server/src/modules/events/events.module.ts
JwtModule.register({
  secret: process.env.JWT_SECRET || 'house_pro_jwt_secret_key_change_in_production',
  signOptions: { expiresIn: '7d' },
}),
```

**验证**：改后 `ping` → `pong` 成功 ✅。
