## 1. 文档概述

### 1.1 模块定位
本系统为面向 **长租公寓运营商** 的 SaaS 管理平台，本次整理的 4 个模块同属一级菜单 **「租赁管理」** 下的核心业务：

| 模块 | 角色 | 业务目标 |
|---|---|---|
| 整租管理 | 房间级业务管理 | 对整租户型房源进行全生命周期运营：登记、跟进、租客签约、退房、缴费 |
| 合租管理 | 套房+分间管理 | 对合租公寓按「套 → 房间」两层结构管理，支持分间出租、利润核算 |
| 储备房源 | 房源储备（拿房前） | 管理未签房东合同的潜在房源，跟进后流转到拿房签约环节 |
| 储备客源 | 客源储备（签约前） | 管理意向租客客源，跟进后通过「租客签约」转化为在租客户 |

四模块共同构成 **「储备房源 → 拿房 → 整租/合租管理 → 退租 → 储备客源匹配 → 租客签约」** 的闭环。

### 1.2 访问入口
| 入口 | 路径 |
|---|---|
| 一级菜单 | 租赁管理 |
| 二级菜单（路由） | `/renting/exclusive-house`（整租）<br>`/renting/shared-house`（合租）<br>`/renting/reserved-house`（储备房源）<br>`/renting/reserved-customer`（储备客源） |
| 菜单权限 id | `lease`（父级，含整租 `whole_lease` / 合租 `joint_lease` / 储备房源 `reserve_housing` / 储备客源 `reserve_client_source`） |
| 渲染方式 | 整租 / 合租 / 储备房源为 Vue SPA 内嵌组件；**储备客源使用 iframe（`/web/reserve/client/toList?`）嵌入** |

### 1.3 财务管理子模块（v1.1 补充）
财务管理是本系统的第二大业务线，共 16 个子模块。左侧菜单可见 7 个（流水账、欠款统计、收支计划、公寓利润、开票管理、代付管理、财务核算），其余 9 个为功能入口或已弃用的 legacy 页：

| 模块 | 路由 | 入口形式 | 业务定位 |
|---|---|---|---|
| 记账 | `/finance/book-keeping` | 入口按钮 | 弹出单据记账窗口（在流水账中使用） |
| 批量财务记账 | `/finance/batch-review` | 入口按钮 | 批量录入财务账目 |
| 账单 | `/finance/account-bill` | 主入口 | 应收应付账单的全生命周期管理 |
| 涨价统计 | `/finance/rent_increase_statistics` | 主入口 | 租客合同涨价幅度统计 |
| **流水账** | `/finance/daily-account` | 主入口 | 单据流水的核心台账（推荐新版） |
| 流水账（legacy） | `/finance/daily-account-legacy` | 已弃用 | 保留旧版路径用于兼容 |
| **公寓利润** | `/finance/rights-and-responsibilities` | 主入口 | 利润核算（权责发生制） |
| 合伙人 | `/finance/partner` | 主入口 | 合伙人分红/分成管理 |
| 收入成本 | `/finance/income-cost` | 主入口 | 收入与成本确认（权责制） |
| **业绩核算** | `/finance/performance-index` | 主入口 | 房源 / 出房 / 拿房 / 员工业绩分配 |
| **财务核算** | `/finance/financial-accounting` | 主入口 | 收入成本汇总 + 毛利核算 |
| 收款（legacy） | `/finance/old-embedded-new-debts` | 已弃用 | 旧版收款入口 |
| **欠款统计** | `/finance/arrears-statistics` | iframe | 应收应付欠款明细（嵌入 `/web/finance/getArrearagePage?`） |
| **收支计划** | `/finance/income-expenditure-plan` | iframe | 计划类应收应付（嵌入 `/web/irrelevant/housing/plan/toIrrHsgPlanListPage`） |
| **代付管理** | `/finance/paying-for-another` | iframe | 对外代付款项管理（嵌入 `/web/entrust/toEntrustList?`） |
| **开票管理** | `/finance/billing-management` | 主入口 | 发票申请、跟踪、归档 |

## 4. 合租管理

> 路由：`/renting/shared-house` · 套房 + 分间两层结构

### 4.1 与整租管理的差异
合租管理与整租管理共用相同的页面框架（综合查询、筛选、卡片视图），区别在于：
1. **数据结构**：合租以「套」为父级（一个房东合同对应一套房源），套下挂多个「间」（合租房间）；
2. **新增筛选维度**：运营状态、业务状态、配置脏房；
3. **新增批量操作**：批量录入房源；
4. **卡片展示**：套信息 + 套下房间明细，并展示「套利润」。

```

│ 【本套总租客租金：0 元  总租客押金：0 元  本套利润：-5000 元】                  │
│ 房东 李四  ￥5000   1302   3室2厅   到期 2031-08-13   合同 5年【免租5月】未装修    │
```

### 4.4 卡片字段
**套信息（外层卡片）：**
- 物业完整地址（含省市区、详细地址、店面归属）
- 套利润看板：`本套总租客租金 / 总租客押金 / 本套利润`
- 房东信息：房东姓名、房东收租（￥）、门牌号、户型、合同到期、合同期限、免租期、装修进展

**房间明细（套下卡片）：**
- 房间状态：空 / 已租 / 退 / 配置 / 脏房 / 维修 / 定
- 空置天数 / 定金金额
- 定价（￥）
- 房间编号：1号房 / 2号房 / 主卧1号房 / 主卧2号房…
- 房型：主卧 / 主卧独卫 / 次卧 / 次卧独卫 / 小卧 / 明隔 / 暗隔 / 明隔独卫 / 可自定义房型
- 已租时显示：租客姓氏、租价、合同到期、缴费状态、合同期限

### 4.5 房型 / 房间状态枚举
**房型：** 主卧、主卧独卫、次卧、次卧独卫、小卧、明隔、暗隔、明隔独卫、可自定义房型（系统支持用户自定义房型）

**房间状态：**
| 状态 | 含义 |
|---|---|
| 空 | 未出租 |
| 已租 / 租客姓氏 | 已出租，显示租客 |
| 定 | 已收定金，未签约 |
| 退 | 退房流程中 |
| 配置 | 装修配置中 |
| 脏房 | 退房后待保洁 |
| 维修 | 维修中 |

### 4.6 顶部按钮
| 按钮 | 行为 |

| 批量 ▼ | 批量录入租客 / 批量录入房间价格 / 批量导入账单 / 批量录入特色标签 / **批量录入房源** |

## 8. 业务流程

### 8.1 房源全生命周期
```
[储备房源 录入]
   ↓ 跟进
[拿房成交] ─── 签房东合同 ─── 进入「合同管理 > 房东合同」
   ↓ 自动流转
[整租管理 / 合租管理 / 集中管理] ── 房间登记到房间信息卡
   ↓
[租客交定] ─── 房间状态变为「已定」
   ↓
[租客签约] ─── 房间状态变为「已租」 ── 进入「合同管理 > 租客合同」
   ↓
[退房] ─── 房间状态变为「退」 ─── 进入退房审批 ─── 退回「未租」
   ↓
[配置 / 脏房 / 维修] ── 装修或保洁流程 ── 重新可租
```

### 8.2 客源全生命周期
```
[储备客源 录入求租]
   ↓ 跟进 / 带看
[客户状态流转]：未租 → 电话未接听 / 暂不租 / 已定
   ↓
[转到整租 / 转到合租 / 转到集中] ── 跨模块流转到对应房间管理
   ↓
[租客签约] ── 客户状态变为「已租」
```

### 8.3 跨模块联动
- **储备房源 → 整租/合租管理**：通过「拿房签约」自动创建房间卡片；
- **储备客源 → 整租/合租管理**：通过「转到整租/合租/集中」转入对应模块；
- **整租/合租管理 → 合同管理**：签约 / 退房自动生成合同记录；
- **整租/合租管理 → 财务管理**：账单、押金、欠款自动同步到流水账、欠款统计。

## 11. 已知体验细节

1. **登录后首屏弹窗**：「我的待办」对话框默认弹出，显示审批流程、巡房逾期提醒、在线反馈等待办项，需逐条处理后才能关闭；右上角「首页设置」可配置不自动弹出。
2. **下载客户端提示**：访问页面时弹出「下载桌面客户端」提示，可关闭或「不想下载」。
3. **储备客源 iframe 隔离**：储备客源模块独立 iframe 实现，主框架通过 postMessage 通信；URL 带 `?` 后可附加筛选参数。
4. **路由方式**：整租/合租/储备房源为 Vue 2 SPA 路由（`#/renting/xxx`），储备客源为 iframe。
5. **密码加密**：登录密码使用 RSA 公钥加密传输（`pubkey` 字段配置，jsencrypt 库）。
6. **WebSocket 多通道**：连接 `ws://127.0.0.1:4649/WebServer`、`8102`、`8765` 等本地服务，用于桌面客户端集成。
7. **空置预警**：首页有空置预警详情弹窗，可设置空置天数阈值，跨店面统计空置房间。
8. **房源概况首页**：登录后工作台首页含智能设备、房源概况、合同管理、空置预警、财务流水、押金统计、我的待办等多个数据卡片。
9. **多店面切换**：顶部支持城市 + 店面级联切换（如「北京市 +1」展开全部店面）。
10. **财务双日历遮挡**：登录后多个财务管理模块会自动弹出日期选择器（双月日历），遮住主表格区域，截图显示空屏；通过 CSS 强制隐藏后文本提取可正常工作。
11. **财务 iframe 协议**：欠款统计、收支计划、代付管理三个财务模块使用 iframe（`/web/.../toListPage`），主框架通过 hash 路由切换；iframe 内的 hover、按钮点击事件不会冒泡到主框架。
12. **业绩偏好设置**：业绩核算模块支持「业绩偏好设置」自定义分配规则（管家 / 收房 / 出房 / 中介的多方分成比例）。
13. **权责发生制**：公寓利润与收入成本模块基于权责发生制（按月分摊计租天数），而非现金收付；与「流水账」现金收付形成对比。
14. **开票申请流程**：开票管理支持租客发票 / 房东发票 / 公司主动申请三类来源，状态经历 待处理 → 开票中 → 已开票，已开票可作废（已冲红）。

### 13.14 财务模块业务流程

#### 13.14.1 账单全生命周期
```
[租客签约] / [房东签约]
    ↓ 自动生成账单
[应收 / 应付]  →  应收付日
    ↓
[到期前]  →  待收 / 待付
    ↓
[收 / 付]  →  实收 / 实付  →  终审  →  出纳
    ↓                              ↓
[已收 / 已付]                      [未出纳财务] → [已出纳]
    ↓
[超期未付]  →  逾期
    ↓
[冲红 / 退账]  →  冲红流水
```

#### 13.14.2 利润核算（权责发生制）
```
合同开始
    ↓
按月分摊（计租天数 / 应收付日）
    ↓
[收入] 租金收入 + 其他收入
[成本] 租金成本 + 其他成本
    ↓
毛利 = 收入 - 成本
    ↓
毛利率 = 毛利 / 收入 × 100%
    ↓
公寓利润表（汇总）→ 系统外挂入（补充项）→ 最终利润
```

#### 13.14.3 业绩分配流程
```
[房源签约] → 房源产生业绩
    ↓
[管家 / 收房业务员 / 出房业务员] 按规则分成
    ↓
[房源总业绩] = 已分配业绩 + 留存转移 + 留存业绩
    ↓
[业绩偏好设置] 控制分配规则
    ↓
[员工业绩报表] → 工资核算
```

#### 13.14.4 代付与开票联动
```
[代付管理] → 提交代付批次 → 批量下载 → 财务确认 → 银行支付
                                              ↓
                                       [开票管理] → 申请发票
                                              ↓
                                       [开票主体] → 销方公司
                                              ↓
                                       [开票记录] → 待处理 → 开票中 → 已开票
                                              ↓
                                       [已开票] 推送至租客 / 房东
```

#### 13.14.5 跨模块联动
| 触发源 | 联动模块 | 联动动作 |
|---|---|---|
| 整租 / 合租 / 集中管理（合同签约） | 账单 | 自动生成应收 / 应付账单 |
| 租客 / 房东合同（退房） | 账单 | 自动生成冲红账单 |
| 租客 / 房东合同（涨价） | 涨价统计 | 涨价金额进入统计 |
| 合同（开始） | 收入成本 | 按月分摊计租 |
| 房源（签约） | 业绩核算 | 房源总业绩累计 |
| 代付（提交） | 开票 | 财务确认后可申请发票 |
| 账单（出纳） | 公寓利润 | 平账后进入利润核算 |

## 附录 C：抓取方法说明

本次抓取使用 Playwright（Chromium headless）自动化登录系统后访问各模块路由，通过以下技术获取页面内容：

1. **登录流程**：访问 `https://quanfangtongvip.com/` → 填入账号密码 → 点击 `#ch_login_btn` → 系统使用 RSA 公钥加密密码后提交 → 跳转至 `#/home`。
2. **路由导航**：通过 Vue Router 实例 `rootVue.$router.push(route)` 进行 SPA 路由切换；同时配合 `window.location.hash` 双重保险。
3. **弹窗处理**：登录后系统默认弹出「我的待办」对话框与「下载客户端」提示，通过 CSS 强制隐藏 `.v-dialog__wrapper`、`.el-dialog__wrapper` 等遮罩层确保页面内容可被提取。
4. **iframe 处理**：储备客源模块使用 iframe 嵌入 `/web/reserve/client/toList?`，通过 `page.frames()` 遍历所有 frame 提取内容。财务管理的 **欠款统计、收支计划、代付管理** 同样使用 iframe（`/web/finance/getArrearagePage?`、`/web/irrelevant/housing/plan/toIrrHsgPlanListPage`、`/web/entrust/toEntrustList?`）。
5. **数据提取**：对每个模块截图（fullPage）+ 提取 `document.body.innerText`，并解析按钮、Tab、表单字段、表头、行级操作等结构化信息。
6. **日历弹窗遮挡**：登录后多个 SPA 模块在打开时会自动弹出日期选择器（双月日历），遮住主表格区域；通过 CSS 强制隐藏 + 后续文本提取可绕过；截图会显示空屏，但文本内容完整。
