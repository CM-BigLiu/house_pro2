## 1. 文档概述

### 1.1 模块定位
"租售房源"是 ERP 中 **房客管理** 下的核心房源资源管理模块，承担经纪人 / 门店对 **二手房出售房源** 与 **租房房源** 的录入、维护、跟进、筛选与流转的全生命周期管理。

### 1.2 业务目标
- 统一管理门店所有租售房源的录入、状态变更、质量评估与跟进；
- 通过丰富的筛选 / 排序维度支持经纪人快速定位目标房源；
- 与"全城联卖"、"客户管理"、"新房报备带看"、"带看管理"、"成交房源"等模块打通，形成"房 - 客 - 带看 - 合同"闭环。

### 1.3 访问入口
| 入口 | 路径 |
|---|---|
| 菜单一级 | 房客管理 |
| 菜单二级 | 租售房源 |
| 菜单三级（路由） | `/house_resource/sale`（二手房）、`/house_resource/rent`（租房） |
| 菜单权限 | `permiId=817239280366657536`，pay=1 |

## 5. 新增房源录入（4 步向导）

入口：列表右上角 **`+ 新房源录入`** 按钮。

向导采用 Element UI 的 `el-steps`，共 4 步：

```
[1] 楼盘选择 → [2] 基本信息 → [3] 特色信息 → [4] 完成
```

### 5.1 Step 1 — 楼盘选择

> 该步骤的核心是 **基于"小区 → 楼栋 → 单元 → 房号"四级级联** 完成房源定位。

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| 租售类型 | ✅ | 下拉 | 二手房 / 租房（决定后面步骤的字段集合） |
| 房屋用途 | ✅ | 下拉 | 普通住宅 / 别墅 / 商住两用 / 车位 / 商铺 / 写字楼 / 厂房 / 土地 |
| 小区选择 | ✅ | 自动补全 | 输入关键词（如"三槐家园"），从建议列表选目标小区 |
| 城市 | 自动 | 文本 | 随小区联动 |
| 小区地址 | 自动 | 文本 | 随小区联动 |
| 栋座 | ✅ | 级联 | 选定小区后加载 |
| 单元 | ✅ | 级联 | 选定栋座后加载 |
| 楼层 | ✅ | 级联 | 选定单元后加载 |
| 房号 | ✅ | 级联 | 选定楼层后加载 |

**容错机制**：右上角 `楼盘信息有误？` 链接 → 报错房源信息，方便修正底层楼盘数据。

## 9. 业务流程

### 9.1 房源主流程
```
[业主委托]
   ↓
[经纪人预录入] ─── 我的预录入房源
   ↓
[正式录入 / 楼盘选择 → 基本信息 → 特色信息 → 完成]
   ↓
[验真] (可选)
   ↓
[上架 / 加入全城联卖] ─── 租售房源
   ↓
[议价 / 调价]
   ↓
[带看 / 客户匹配] ─── 与"客户管理"/"带看管理"联动
   ↓
[签约] ─── 成交房源
   ↓
[下架 / 归档]
```

### 9.2 跟进 SLA
- 系统提示"X 天未跟进"，触发跟进按钮
- 房源质量分与跟进频率强相关（每日跟进 → 高分；久未跟进 → 降级）

### 9.3 验真 / 速销流程
- 政府核验码录入 → 提交官方核验 → 验真状态变更
- 速销：与业主签订速销协议，设定速销起始 / 截止日期；到期自动转议价或下架
