## 四、快速启动步骤

```bash
# 1. 启动数据库（PostgreSQL + Redis）
cd code/server
docker compose up -d

# 2. 运行数据库迁移
npm run migration:run

# 3. 注入种子数据（含本表账号与业务数据）
npm run seed

# 4. 启动后端
npm run start:dev
# 或生产模式
node dist/main

# 5. 启动前端
cd code/web
npm run dev
```

## 六、常用测试场景

### 6.1 验证数据权限
1. 用 `super_admin` 登录，进入「售房管理」，确认看到 3 套房源
2. 退出后用 `agent02` 登录，进入「售房管理」，确认只看到 1 套
3. 用 `salesman` 登录，确认看不到 `agent02` 创建的房源

### 6.2 验证黑名单预警
1. 用任意账号登录，进入「房源录入向导」
2. 选择「售房」→ 选择小区/楼栋/房号 → 填写房屋信息
3. 在 Step4 业主电话输入 `13800138001` 或 `13900139002`
4. 失焦后应弹出「黑名单预警」弹窗

### 6.3 验证小区级联
1. 进入「房源录入向导」Step2
2. 选择「张江汤臣豪园」
3. 楼栋 → 单元 → 楼层 → 房号应逐级联动加载

### 6.4 验证看板真实数据
1. 用 `boss` 登录首页
2. KPI 卡片应显示：在管房源 4 套、在租房间 3 间、空房间 1 间、储备客源 2 人
3. 预警卡片应显示黑名单人员 2 人
4. 排行榜、待办、月度趋势图均基于真实数据统计

## 七、重置数据

如需清空并重新注入种子数据：

```bash
cd code/server
docker compose down -v
docker compose up -d
npm run migration:run
npm run seed
```

> 注意：`-v` 会删除 PostgreSQL 数据卷，所有业务数据将重置为种子初始状态。
