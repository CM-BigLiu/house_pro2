## 偏差与修复建议

### P1-1 客户管理应为卡片视图（U-029 / C-005）
- 位置：`UI/assets/js/data-base.js:181`，customer 块 `layout: 'table'`
- 修复：改 `layout: 'cards'`，columns/rows 换成 `cards`，字段含脱敏手机号/身份证/黑名单红色标记（C-008），actions 保留 `permission` 键维持按钮级权限

### P1-2 缺删图模式（§5.2.4 / UX-007 / U-030）
- 位置：sale/rent 配置、`ui-render.js`、`ui-main.js`、`ui.css`
- 修复：cards 加图片位（`.card-thumb`）→ 页头加「删图模式」按钮 → 点击给 `.content` 切 `no-image` class → CSS `.content.no-image .card-thumb{display:none}`

### P2-3 日期筛选应为区间（§5.2.3）
- 位置：`ui-core.js` `filtersHtml`、sale filters
- 修复：`filtersHtml` 支持 `type:'range'` 双输入；售房发布/新增/更新价格/下架/议价/速销日期改区间；首付/底价/售价/面积等成对字段建议统一改 range

### P2-4 售房排序区渲染语义混用（§5.2.4）
- 位置：`data-base.js` sale 页 `views`、`ui-render.js:22`
- 修复：sale 的 `views`（存的实为排序字段）改名 `sorts`，单独渲染 sort-bar（默认"发布时间 ▾"倒序）；租房页 `views` 保持不动

### P2-5 看板视图角色不全（§4.13.3 / §4.14）
- 位置：`ui-core.js:37-44` PROTOTYPE_ROLES、`ui-render.js:234-239` roleGroups
- 修复：补 `boss`/`company_admin`/`finance_clerk`/`agent` 四角色并映射看板分组；菜单 roles 同步补 agent（售房/储备/客户）与 finance_clerk（账单/流水/欠款）

### P2-6 账单「更多筛选」偏少（§6.1.1）
- 位置：`data-finance.js` bill/flow filters
- 修复：补收付款人、管家、房源编号 3 项

### P2-7 缺「我的待办」首屏弹窗（§13.1 / UX-001）
- 位置：`ui-render.js` renderDashboard
- 修复：加 `<dialog data-todo-dialog>`（审批/巡房逾期/反馈回复计数），非 readonly 角色进入首页时 `showModal()`；「首页设置」可配置关闭（UX-002）

### P3-8 小区管理应为区域分组卡片（§5.6.1）
- 位置：`data-base.js` community
- 修复二选一：
  - **A（推荐）**：保持树+表格，左树改「区域 → 小区」分组即可，验收只验字段完整性
  - **B**：改 `layout:'cards'` + `cardGroups` 按区域分组，成本较高
