| action | 用途 |
|--------|------|
| start  | 启动某 role 实例 |

| logs   | 查看完整日志 |
| tail   | 查看末尾 N 行日志 |

**ROLE / INSTANCE 来源**：
- **ROLE**：从上方 `stage.environment.hooks` 的顶层 key 选取（如 `backend` / `agent` / `frontend`）

- **示例**：若要启动 backend 服务并查看日志，命令为：

  ```
    --session auth-token-refresh --env dev-local --role backend --instance backend-1 \
    --action start --skill pg-build
  ```
