# 房屋租售 ERP Computer Use UI 测试报告

## 1. 测试概况

- 测试地址：`http://127.0.0.1:5173/`
- 测试日期：2026-09-14（Asia/Shanghai）
- 测试方式：Codex Computer Use 驱动真实浏览器，按用户可见界面操作并核对 DOM、下载事件及浏览器控制台
- 数据源：本地前端 `5173` + 本地模拟 API `127.0.0.1:3000/api`
- 测试账号：`super_admin`、`boss`、`store_manager`、`salesman`、`finance`、`housekeeper`，密码均为测试环境提供的 `123456`
- 覆盖范围：登录、退出、首页、搜索、筛选、重置、分页、角色权限、房屋管理 9 个业务页、财务管理 12 个业务页、系统管理 5 个业务页，以及页面上可见的主要按钮和 CRUD 入口
- 编码：报告及测试数据均使用 UTF-8
- 说明：AGENTS.md 要求使用 Context7，但当前会话没有可用的 Context7 工具；本次 UI 测试不依赖外部文档。

## 2. 初测总体结论（修复前）

当前版本不建议进入验收。登录与大部分列表展示可用，部分新增、编辑、状态筛选和权限路由可工作；但存在多处阻断性问题：分页只改变页码却不换数据、多个新增表单允许空数据、储备房/储备客/客户/财务数据字段映射错误、多项编辑或业务动作命中 404/500、财务统计出现 `NaN`、单页路由偶发保留旧组件，以及角色权限配置显示为 0 项但运行时权限仍生效。

删除、创建员工账号、保存权限、审批、批量付款及创建财务计划/开票申请等高影响动作尚未执行最终确认，详见第 9 节。

## 3. 重点缺陷

| 编号 | 级别 | 缺陷 | 影响 |
|---|---|---|---|
| BUG-001 | P1 | 多个列表分页只改变激活页码，数据不换页 | 租房、客户、账单、流水账等无法正确分页查看 |
| BUG-002 | P1 | 储备房源、储备客源、客户、流水账等字段映射错误 | 新增后数据丢失、状态/类型错误，业务不可用 |
| BUG-003 | P1 | 财务新增空数据后出现 `NaN` 或渲染异常 | 涨价、利润、计划页面统计失真并触发运行时错误 |
| BUG-004 | P1 | 多个业务动作请求 404/500 | 储备房转业务员、储备客跟进、员工编辑、账单作废等失败 |
| BUG-005 | P1 | 角色管理中所有角色均显示“0 项权限”，但运行时菜单和直链权限仍按角色生效 | 权限配置数据与实际鉴权规则不一致，无法可信管理权限 |
| BUG-006 | P1 | 角色和字典项允许空值直接创建 | 产生无名称、无编码的无效基础数据 |
| BUG-007 | P1 | 单页菜单跳转偶发仅改变 URL/面包屑，主体保留“收支计划”旧组件 | 代付、开票、系统管理页面从侧栏进入时不可用；直接刷新后才显示正确页面 |
| BUG-008 | P2 | 导出按钮普遍无下载、无提示、无控制台错误 | 用户无法判断是否执行成功 |
| BUG-009 | P2 | 多个“编辑 / 详情 / 明细 / 查看”按钮无任何响应 | CRUD 链路不完整 |
| BUG-010 | P2 | 所有角色头像区域身份文本均显示“管理员” | 角色身份展示错误，易造成权限误判 |
| BUG-011 | P2 | 错误登录同时显示两条重复提示 | 用户体验重复且不一致 |
| BUG-012 | P2 | 押金确认文案出现 `¥¥`，利润率出现 `%%` | 金额与百分比格式错误 |
