## 交互走查要点（需在浏览器手动操作）

1. **角色切换**：顶栏下拉切换 10 种角色 → 菜单、按钮、看板分组即时重渲染（`localStorage` 持久化）。
2. **删图模式**：租房/售房页点「删图模式」→ 卡片缩略图隐藏，按钮高亮；再点恢复。
3. **排序区**：售房页 sort-bar 单选切换 active 态。
4. **更多筛选**：售房页点「更多筛选」→ 详细筛选（数值/日期区间等 30+ 项）展开，按钮变为「收起筛选」且箭头翻转。
5. **Tab 切数据**：租房（房间/房东）、流水账（4 子 Tab）、公寓利润（5 子表）、账单（工作台/账单）、人员管理（6 Tab）点击 Tab 即时重渲列表区。
6. **角色配置**：角色管理页左侧角色列表点击切换选中；菜单权限树 checkbox 父子级联勾选；「保存配置」回执。
7. **录入向导**：步骤条点选 / 上一步 / 下一步；「业主校验」触发黑名单弹窗；标签多选；跟进内容 0/500 字数统计；业主电话为空点「发布」提示「手机号不可为空」。
8. **待办弹窗**：首页非只读角色首屏自动弹出；点「首页设置」后本会话不再弹出（UX-002 原型态）。
9. **树选中**：小区/角色/权限/字典/人员页左树节点点击高亮。
10. **Toast 反馈**：所有占位按钮点击均有操作回执。

## 已知边界（原型声明）

- 数据为静态演示数据，筛选/搜索/分页为交互示意，不执行真实查询。
- 删图模式、待办弹窗关闭状态均按会话暂存（`sessionStorage`），真实实现按用户偏好存后端（UX-002）。
- 弹窗类（详情/编辑/新增）按原型约定以 Toast 示意，不落真实表单。
