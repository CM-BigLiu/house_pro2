## 四、P0 修复的核心验证

针对 BUG-1（refresh 契约断裂），做了完整的链路验证：

1. 登录 → 前端本地存储 `house_access_token` + `house_refresh_token` ✅
2. 模拟 access token 过期（篡改为无效值）→ 刷新页面触发 401 ✅
3. 前端拦截器自动调 `/auth/refresh` → 重放原请求 ✅
4. **access token 被正确更新为新值**（不再是无效值）✅
5. **refresh token 原样保留，与登录时完全一致**（P0 修复生效）✅

结论：`refresh` 现在正确返回 `{ accessToken, refreshToken }`，前端 `doRefresh` 覆盖存储后 refreshToken 不再丢失，「7 天静默续期」恢复为预期行为。
