# 房屋租售管理系统（house_pro）

面向房屋租售一体化运营的 ERP 管理平台产品仓库，包含产品需求文档、验收文档与高保真原型。系统覆盖**房源全生命周期、客源全生命周期、财务全链路、系统配置中心**四大领域。

## 核心模块

| 一级菜单 | 包含功能 | 说明 |
|---|---|---|
| **首页** | 工作台看板 | 经营数据一览 |
| **房屋管理** | 租房管理、售房管理、储备房源、储备客源、客户管理、小区管理 | 房源 + 客源 + 小区 |
| **财务管理** | 账单、流水账、涨价统计、公寓利润、合伙人、收入成本、业绩核算、财务核算、欠款统计、收支计划、代付管理、开票管理 | 12 个财务子模块 |
| **系统管理** | 角色管理、权限管理、字典管理、人员管理 | RBAC 配置中心 |

## 设计要点

- **权限到店**：RBAC 三元模型（角色 + 数据范围 + 权限点），数据范围支持「我的 / 本组 / 本店 / 全部 / 指定店面」
- **字段驱动**：业务枚举值全部走字典配置，新增选项无需改代码
- **模板化**：合同、短信、微信菜单均通过模板配置生效
- **审计透明**：所有设置变更写入操作日志，可追溯到人、时间、IP
- **卡片优先**：房源/客源列表默认 card 卡片视图，4 步向导式录入

## 原型预览

`codex/` 为纯静态页面，无需构建，直接用浏览器打开 `codex/index.html` 即可浏览，或本地起一个静态服务器：

```bash
cd codex
python -m http.server 8080
# 访问 http://localhost:8080
```
